## ✨ 特性

- 纯手绘 SVG + CSS 动画，无任何外部依赖
- 车轮旋转、脚踏蹬动、鲸鱼尾巴摆动、鲸鱼鳍耳抖动、长发飘动、身体起伏、气泡上浮、云朵飘动
- 点击画面可以让鲸鱼娘加速「冲鸭」🐳💨
