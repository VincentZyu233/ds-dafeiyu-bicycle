## ✨ 特性

- 纯手绘 SVG + CSS 动画，无任何外部依赖
- 车轮旋转、脚踏蹬动、尾巴摆动、鱼身起伏、气泡上浮、云朵飘动
- 点击画面可以让大肥鱼加速「冲鸭」🐟💨
